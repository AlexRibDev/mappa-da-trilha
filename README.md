# Mappa da Trilha

Jogo web pra ajudar jovens dos Ramos Sênior e Pioneiro a escolher qual oficina
(eixo de desenvolvimento) seguir na Feira de Especialidades. O jogador explora
um mapa, coleta itens ligados às 32 especialidades do guia oficial, escolhe
até 9 pra levar, e entrega pro chefe escoteiro, que sugere um ranking de
afinidade entre os 4 eixos: Meio Ambiente, Paz e Desenvolvimento, Saúde e
Bem-estar, Habilidades para a Vida.

## Versões

- `versions/3d-threejs/` — primeira versão jogável, mapa em 3D (Three.js),
  câmera que segue o personagem, casinha do chefe, NPCs, cenário temático por
  eixo. Funcional, mas com acabamento visual simples (formas geométricas).
- `versions/2d-illustrated/` — (em andamento) nova versão com mapa 2D
  ilustrado, inspirada nos mapas clássicos de Super Mario Bros/World, visando
  um acabamento visual muito mais rico.

Se a versão 2D não ficar boa o suficiente, a 3D fica como alternativa pronta.

## Como abrir

Cada versão é um único arquivo HTML autocontido (`index.html`) — não precisa
de build nem de servidor, dá pra abrir direto no navegador.
